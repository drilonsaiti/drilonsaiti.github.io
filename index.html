AutoScout24 inventory as a native WordPress experience

A custom plugin that synchronises dealership inventory into WordPress so the website owns the browsing experience instead of relying on an iframe or manually maintained listings.

Problem
Embedded or manually maintained vehicle listings gave the dealership limited control over UX, filtering and multilingual presentation.
What I built
Automatic inventory sync, advanced vehicle search and filters, responsive cards and lists, German and French support, and Elementor-compatible rendering.
Outcome
The live website keeps its inventory current automatically while retaining full control over the frontend experience.
Sync layer
Server-side AutoScout24 authentication and scheduled WordPress Cron jobs keep the local inventory in sync.
Data flow
Vehicle data is stored locally in WordPress, so normal visitor traffic reads local data instead of repeatedly calling the upstream API.
Security
API credentials remain server-side and never need to be exposed to website visitors or frontend JavaScript.
